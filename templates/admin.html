How It Works

  1. Casinos are managed in CasinoData - changes sync automatically on page refresh
  2. Create a subdomain (e.g., "blackjack")
  3. Toggle which global URLs appear on each subdomain
  4. Visit https://blackjack.bookmarks.dougshipe.com to open enabled sites
